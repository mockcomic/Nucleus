Three things worth knowing

  • 1
    Every action type is one segment — apps, links, files, shell commands, keystroke macros, and built-in Windows actions (lock, mute, screenshot…) all configure the same way in Settings → Segments.
  • 2
    Settings previews live — the right-hand panel draws the real wheel renderer while you edit; every change autosaves, with undo for the regrettable ones.
  • 3
    The tray is the cockpit — right-click the tray icon to show the wheel, open settings, pause the hotkey, or replay this welcome. Gaming mode can switch the wheel off automatically while you play.
