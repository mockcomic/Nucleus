Hotkey & behavior

Summon hotkey
Ctrl + Alt + Space
Click “Change…”, then press any modifier combination (Ctrl/Alt/Shift/Win + key). It registers instantly — if the combo is taken by another app you'll be told and the old hotkey stays active.

Advanced

Config file
Stored in %APPDATA%\Radial Wheel\config.json — edits are watched live.
Action types
  • app — launch a program or open a file (paths or shell names like notepad.exe)
  • url — open a link in your default browser
  • command — run any shell command
  • macro — synthesize keystrokes: ctrl+c, wait=0.2, ctrl+v · type:hello world
  • sys — built-in Windows actions (lock, sleep, volume, settings pages…)
