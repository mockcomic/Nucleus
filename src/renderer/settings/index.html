Wheel behavior
Gaming mode
The wheel switches itself off (hotkey included) while the focused app covers a whole monitor — exclusive or borderless-fullscreen games — or while one of the listed programs has focus. Comma-separated exe names; full paths are fine. The tray tooltip says why the hotkey is off, and tray → Show wheel still works.

Advanced

Config file
Stored in %APPDATA%\Radial Wheel\config.json — edits are watched live.
Action types
  • app — launch a program or open a file (paths or shell names like notepad.exe)
  • url — open a link in your default browser
  • command — run a shell command (cmd.exe syntax — type it) or a .bat / .cmd / .ps1 script (type the path or use Browse…)
  • macro — synthesize keystrokes: ctrl+c, wait=0.2, ctrl+v · type:hello world
  • sys — built-in Windows actions (lock, sleep, volume, settings pages…)
