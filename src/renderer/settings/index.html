Summon hotkey
79|
80|
81|
Ctrl + Alt + Space
82| 83|
84|
Click “Change…”, then press Ctrl, Alt, Shift, or Win plus a key. Ctrl + Alt + Space is the usual choice. A mouse button — Middle, Back, or Forward, with or without a modifier — is the alternative. It registers instantly — if the combo is taken by another app you'll be told and the old hotkey stays active.

Wheel behavior
93|
94| 95| 100|
101|
Where programs opened from the wheel place their window: left to the app, pulled under the mouse, or centered on the monitor your mouse is on (taskbar excluded). Only freshly-opened windows move — apps that raise an already-open window, or that start maximized, keep their spot. The wheel itself always opens under the cursor. Takes a few seconds as the program starts.
102| 103| 104| 105| 106|
Only applies when the shortcut's main key is a mouse button: Middle, Back or Forward. Off (the default) means the wheel treats it like a real hotkey and the app never sees the click — so Middle click stops pasting while it is your summon button. Turn it on if you want both.
107| 108|
The pie-menu way: hold the left button anywhere on the wheel, sweep (folder fans branch as you pass), and release on a segment to fire it. Releasing off the wheel cancels. Ordinary clicks still work exactly as before.
109| 110|
Start typing and non-matching segments fade back; the selection jumps to the best match and Enter fires it. Backspace edits, Esc clears the query. Folder sub-menus open themselves when their contents match.
111| 112|
A gentle blip when the selection lands on a segment and when a segment fires. The ticks are synthesized on the fly (no audio files, no network); off by default.
113| 114|
When a program segment fires and that app already has a window on screen, the existing window comes to the front instead of a second copy starting — a running app with no window (tray-only) still launches normally. Applies to segments that point at an .exe; shortcuts, scripts, and links always open as before. Off by default.
115| 116|
A few seconds after startup and once a day, Nucleus asks the GitHub Releases page whether a newer version is out — and if there is one, it asks you before doing anything. "Update now" downloads the published installer to your Downloads folder, checks its SHA-256 against the one GitHub published, and runs it after confirming; Nucleus quits while the update installs and your settings stay put. "Open release page" and "Later" are always offered, and nothing is ever installed without a yes. Turning this off stops the background check; the manual "Check for updates" in the tray menu and below still works.
Off by default: a pasted icon URL must be HTTPS and can never point at your own machine or network (127.0.0.x, 192.168.x.x, 10.x, …), so a bad URL can’t probe your LAN. Turn this on only if an icon genuinely lives on a box you own — it also allows plain http for icon downloads.

App profiles
134| 135|
When on, each wheel opening checks the app you are focused in — the first profile listing that program takes over, until you focus something else. Manage profiles at the top of the Segments tab. Uses the same focus probe as Gaming mode; nothing runs in the background while this is off.

Config file
208|
Stored in %APPDATA%\Nucleus\config.json — edits are watched live.
209|
210| 211| 212| 213| 214| 215| 216| 217|
218|
A package is a single file with your whole setup plus the bytes of every custom segment image — share it and the wheel arrives fully decorated. A plain Export carries config only (logos and URL-picked icons re-download themselves).
219|
Before Import… or Reset replaces your config, the outgoing file is copied to %APPDATA%\Nucleus\backups and the newest 12 are kept — Restore a backup… opens that folder. Autosaves are kept out of the rotation (one at most every few minutes), so a burst of typing can't bury the useful copies.

Action types
233|
    234|
  • Open a program (app) — launch a desktop app (paths or shell names like notepad.exe), with an optional Arguments box for launch parameters such as --flag "C:\path with space"
    • 235|
  • Open a website (url) — open a link in your default browser
    • 236|
  • Open a file (file) — open a document or folder with its default app
    • 237|
  • Windows action (sys) — built-in Windows actions (lock, sleep, volume, settings pages…)
    • 238|
  • App toggle (setting) — flip one of Nucleus's own switches straight from the wheel
    • 239|
  • Folder (folder) — a sub-menu that branches outward when the pointer rests on it
    • 240|
  • Recents (recent) — a self-filling sub-menu of your most-recently-used segments; edit its label and icon, its contents update themselves
    • 241|
  • Run a command or script (command) — run a shell command (cmd.exe syntax — type it) or a .bat / .cmd / .ps1 script (type the path or use Browse…)
    • 242|
  • Macro (macro) — synthesize keyboard and mouse input. Use the Steps helper in the editor, or write the spec directly: ctrl+c, wait=0.2, ctrl+v · type:hello world · click / rclick / mclick / dblclick / back / forward · scroll=3 (negative = up) · hold=ctrl+c=1.5 · repeat=3:ctrl+v. Mouse steps fire at the current cursor position
    • 243|
244|
The Type dropdown groups these as Everyday actions, Organize the wheel, and Power user — the two technical types sit in that last group.
